# Servers overrides

- Primary action: Import subscription. Refresh, search, and sort are secondary.
- Each server row exposes name, protocol text, source, last verified latency with
  timestamp, and selected state. A tiny colored flag/dot is never the only identifier.
- `—` means unmeasured or unsupported; never show fake local/fake-DNS latency.
- Lists over 100 rows are virtualized while preserving keyboard navigation and focus.
- Import is a labeled dialog with URL/clipboard/file choices, secret masking, validation,
  and a summary before replacing existing nodes.
