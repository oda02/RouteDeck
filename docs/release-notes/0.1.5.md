# RouteDeck 0.1.5

## Исправления

- Исправлена подготовка portable-обновления: проверка папки больше не запрашивает
  право переименования, которое конфликтовало с рабочей папкой запущенного процесса.
  Право переименования запрашивается только при замене после закрытия приложения.
- Исправлены такие же конфликты в папке запуска и работы отдельного обновляющего
  процесса. Проверенные файлы и папки сохраняют блокировку записи и удаления.
- Если права папки разрешают другим пользователям менять приложение, сообщение
  теперь объясняет причину и предлагает полный ZIP в новой личной папке.
  Проверки владельца, прав доступа, подписи и полного состава выпуска сохранены.

## Установка

С 0.1.3 или 0.1.4 установите этот выпуск вручную один раз: скачайте полный
`RouteDeck-0.1.5-windows-x64.zip`, закройте старый RouteDeck обычным способом,
распакуйте архив в новую пустую личную папку внутри папки пользователя и запустите
`routedeck.exe`. Библиотека серверов и настройки хранятся в данных пользователя
Windows и сохраняются. Сохраните старую папку до проверки нового запуска.

Общие writable-папки не подходят для встроенного обновления. Приложение не меняет
права существующей папки автоматически. Старые 0.1.3/0.1.4 не могут получить это
исправление через собственную подготовку обновления.

## Проверка

Регрессионные Windows-тесты используют синтетические файлы, дескрипторы рабочей
папки и враждебные ACL в временных каталогах. Они проверяют подготовку, сохранение
блокировок, замену после закрытия старого процесса и работу из staging-папки.
Реальная замена запущенного GUI и переподключение VPN в этих тестах не выполняются.
